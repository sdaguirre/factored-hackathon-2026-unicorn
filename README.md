# factored-hackathon-2026-unicorn

Asistente de crédito con IA para banca (México, Colombia y Argentina), en español y portugués, para el
**Factored AI & Data Hackathon 2026**.

> Datos y política sintéticos. Ninguna respuesta del asistente es una aprobación de crédito.

El contenido llega por pull requests, en este orden:

1. `feat/backend`: API, verificación por preguntas de seguridad, agente, política de crédito y pruebas.
2. `feat/frontend`: interfaz de chat y `docker-compose`.
3. `feat/data-analysis`: SQL de la capa gold y análisis de datos.
4. `docs/architecture-evaluation`: documentación completa y este README definitivo.

Cada PR describe qué cambia, cómo se probó y qué no cubre.
